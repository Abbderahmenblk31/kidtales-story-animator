# 🌟 منصة حكايات متحركة للأطفال (StoryMotion AI / KidTales Animator)

منصة تفاعلية متطورة موجهة للأطفال والمعلمين وصُنّاع المحتوى، تعمل بالذكاء الاصطناعي لتحويل الرسومات الثابتة ومشاهد القصص المصورة إلى كرتون ناطق ومتحرك بلمسة زر واحدة.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):** Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti.
- **الواجهة الخلفية (Backend & APIs):** Next.js Route Handlers (`/api/generate`, `/api/status/[id]`, `/api/tasks`).
- **قاعدة البيانات (Database):** SQLite مدعومة بمكتبة **Prisma ORM**.
- **محرك المعالجة الفعلي (Real Video Processing Engine):** محرك فيديو محلي حقيقي باستخدام **FFmpeg** يطبق تأثيرات كاميرا كرتونية سينمائية (Dynamic Ken Burns Pan & Zoom, 2.5D Camera movement) بدقة 1080p وبدون أي APIs مدفوعة.

---

## 🛠️ المميزات الرئيسية (Phase 1 Scope)

1. **منطقة رفع مبهجة وتفاعلية (Drag & Drop):**
   - دعم رفع الصور (`.png`, `.jpg`, `.jpeg`, `.webp`) ومشاهد الفيديو (`.mp4`) حتى 25 ميجابايت.
   - معاينة فورية للصورة/الفيديو مع إمكانية التبديل والإزالة.
   - زر خاص: **"تجربة رسمة جاهزة"** للبدء بضغطة زر واحدة دون الحاجة للبحث عن صور.
2. **صانع الأوامر النصية الملهم (Prompt Sparks):**
   - حقل إدخال نصوص ذكي مع عداد للأحرف.
   - بطاقات إلهام جاهزة للأطفال (مثلاً: *"القطة تقفز والولد يبتسم"*, *"فراشات ملونة ترفرف"*, *"غبار سحري ونجوم براقة"*).
3. **متابعة حية للتقدم (Real-time Polling):**
   - فحص دوري آلي كل **3 ثوانٍ** عبر الخطاف `useTaskPolling`.
   - شريط تقدم متدرج مع شريط ألوان متحرك (0% ➔ 100%).
   - مراحل واضحة (استلام المشهد ➔ تحليل الشخصيات ➔ توليد الحركة ➔ الإخراج النهائي).
   - عبارات تشجيعية مخصصة للأطفال تتغير بحسب المرحلة.
4. **استوديو المقارنة التفاعلي (Before / After Comparison):**
   - عرض جنباً إلى جنب (Side-by-side) أو نمط التبديل الفردي (Toggle view).
   - مشغل فيديو مدمج مع تحكم كامل بالتكرار التلقائي (Loop) والتشغيل.
   - احتفال فوري بتأثير الألعاب الورقية (Confetti) عند اكتمال الفيديو.
   - زر تحميل الفيديو الكرتوني الناتج بصيغة MP4 بجودة عالية.
5. **سجل القصص السابقة (Recent Gallery Drawer):**
   - قائمة جانبية تعرض القصص المنفذة سابقاً وتتيح استعراضها في أي وقت.

## 🚦 طريقة التشغيل والتشغيل المحلي

### 1. تثبيت الحزم ومزامنة قاعدة البيانات
```bash
npm install
npx prisma generate
npx prisma db push
```

### 2. تشغيل السيرفر في وضع التطوير
```bash
npm run dev
```

### 3. بناء وتشغيل نسخة الإنتاج (Production)
```bash
npm run build
npm run start -p 3000
```
ثم افتح المتصفح على الرابط: `http://localhost:3000`
